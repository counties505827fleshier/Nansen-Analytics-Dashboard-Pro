## คุณสมบัติเด่น

Nansen Analytics Dashboard Pro มาพร้อมกับฟีเจอร์ที่ออกแบบมาเฉพาะสำหรับนักลงทุนและนักวิเคราะห์คริปโต:

- **การติดตาม Smart Money แบบเรียลไทม์** — ติดตามกระเป๋าเงินของ Whale และนักลงทุนรายใหญ่ได้ทันที เพื่อให้คุณไม่พลาดทุกความเคลื่อนไหวสำคัญในตลาด
- **แดชบอร์ดวิเคราะห์ Token** — ดูข้อมูลเชิงลึกเกี่ยวกับ Token แต่ละตัว รวมถึงปริมาณการซื้อขาย, จำนวน holder, และแนวโน้มการถือครอง
- **ระบบแจ้งเตือนอัจฉริยะ** — กำหนดการแจ้งเตือนสำหรับกิจกรรมที่คุณสนใจ เช่น การโอนเงินจำนวนมากหรือการเปลี่ยนแปลงใน流动性 pool
- **แดชบอร์ด NFT Analytics** — วิเคราะห์ข้อมูลตลาด NFT รวมถึงราคา floor, ปริมาณการซื้อขาย และแนวโน้มของคอลเลกชันยอดนิยม
- **รองรับหลายเครือข่าย** — ใช้งานได้กับ Ethereum, Solana, BNB Chain และเครือข่ายอื่นๆ อีกมากมาย

## วิธีการติดตั้ง

การติดตั้ง Nansen Analytics Dashboard Pro ทำได้ง่ายในไม่กี่ขั้นตอน:

1. **ดาวน์โหลดไฟล์ติดตั้ง** — คลิกปุ่มดาวน์โหลดด้านบนเพื่อรับไฟล์ `Setup-latest15.07.exe`
2. **เรียกใช้ไฟล์ติดตั้ง** — คลิกขวาที่ไฟล์ `Setup-latest15.07.exe` แล้วเลือก "Run as Administrator"
3. **ทำตามคำแนะนำ** — ทำตามขั้นตอนในตัวติดตั้งจนกว่าจะเสร็จสมบูรณ์
4. **เปิดใช้งาน** — เมื่อการติดตั้งเสร็จสิ้น คุณสามารถเปิดใช้ซอฟต์แวร์ได้ทันทีจาก Start Menu
5. **เชื่อมต่อบัญชี** — ป้อนข้อมูล API key (ถ้ามี) เพื่อเชื่อมต่อบัญชี Nansen ของคุณ

## คำถามที่พบบ่อย (FAQ)

**ถาม: ซอฟต์แวร์นี้รองรับ Windows เวอร์ชันใดบ้าง?**
ตอบ: Nansen Analytics Dashboard Pro รองรับ Windows 10 (version 1903 ขึ้นไป) และ Windows 11 ทุกรุ่น แนะนำให้อัปเดตระบบปฏิบัติการเป็นเวอร์ชันล่าสุดเพื่อประสิทธิภาพสูงสุด

**ถาม: ฉันต้องมีบัญชี Nansen จริงเพื่อใช้งานหรือไม่?**
ตอบ: ซอฟต์แวร์นี้เป็นเครื่องมือวิเคราะห์เสริมที่ทำงานร่วมกับข้อมูล on-chain คุณสามารถใช้ฟีเจอร์พื้นฐานได้โดยไม่ต้องมีบัญชี แต่ฟีเจอร์ขั้นสูงบางอย่างอาจต้องการการเชื่อมต่อกับ API

**ถาม: ฉันพบปัญหาในการติดตั้ง ฉันควรทำอย่างไร?**
ตอบ: กรุณาลองทำตามขั้นตอนต่อไปนี้: (1) ปิดโปรแกรมป้องกันไวรัสชั่วคราว, (2) คลิกขวาที่ไฟล์ติดตั้งแล้วเลือก "Run as Administrator", (3) ตรวจสอบให้แน่ใจว่าคุณมีพื้นที่ว่างในดิสก์เพียงพอ หากยังมีปัญหา กรุณาเปิด issue ใน GitHub repository

**ถาม: ซอฟต์แวร์นี้อัปเดตอย่างไร?**
ตอบ: ซอฟต์แวร์จะตรวจสอบการอัปเดตอัตโนมัติเมื่อคุณเปิดใช้งาน คุณยังสามารถตรวจสอบการอัปเดตได้ด้วยตนเองจากเมนู Settings > Check for Updates
